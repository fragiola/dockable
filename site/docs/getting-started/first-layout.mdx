title: Your first layout
description: From a typed JSON layout to a resizable, draggable layout with live content, step by step.
---

This page builds the smallest complete layout: two tabsets side by side, a splitter between
them, tabs you can drag, and panels whose content survives every move. It ends where the
[`hello-layout`](/examples/hello-layout) example starts.

<Steps>

<Step>

## Declare what your tabs hold

Each tab names a **component** (what it shows) and carries **data** (its state). Declare the data
type of each component once, in a registry. Everything below is typed by it:

```tsx title="types.ts"
export type Types = {
    tabs: {
        welcome: undefined;
        notes: { text: string };
        inspector: undefined;
    };
};
```

The tab's `name` is in its data: the model holds no text, so the strip renders what you put there
([Typed data](/docs/concepts/typed-data)).

</Step>

<Step>

## Describe the layout as JSON

A layout is a tree: a **row** splits its space between its children, a **tabset** holds
**tabs**. `weight` is a relative size. A row nested in a row takes the opposite orientation, so
it acts as a column.

<Framework name="react">

```tsx title="layout.ts"
import type { LayoutJson } from "@fragiola/dockable-react";
import type { Types } from "./types";

export const json: LayoutJson<Types> = {
    version: 1,
    root: {
        type: "row",
        children: [
            {
                type: "tabset",
                weight: 60,
                children: [
                    { component: "welcome", label: "Welcome" },
                    { component: "notes", label: "Notes", data: { text: "" } },
                ],
            },
            {
                type: "tabset",
                weight: 40,
                children: [{ component: "inspector", label: "Inspector" }],
            },
        ],
    },
};
```

</Framework>


</Framework>

This is **JSON v1**: `version: 1` and a `root` row. Nodes without an `id` get one when the layout
loads. A tab whose `data` does not match its `component` does not compile. Every field is listed in
[the JSON model reference](/docs/api/json-model).

</Step>

<Step>

## Create the model once

The model is the source of truth. Create it once (not on every render) and keep it:

<Framework name="react">

```tsx
const [model] = useState(() => createModel<Types>(json));
```

</Framework>

<Framework name="vue">

```ts
// in <script setup>: it runs once per component. Never in ref() or reactive(): their proxy is
// not the model the engine knows
const model = createModel<Types>(json);
```

</Framework>

<Framework name="angular">

```ts
// a field of the component: it is created once, with the component
readonly model = createModel<Types>(json);
```

</Framework>

The model keeps its identity for the life of the layout: loading a saved layout or undoing a step
replaces its state in place (`layout.load`), never the model. Recreating it on every render would
reset the layout each time.

</Step>

<Step>

## Render the structure

You own the recursion. `Dockable.Row` calls its child function for every child of the row: a
tabset or a nested row. A tabset renders its tab strip (`TabList` › `Tab`) and marks its content
area (`TabSetContent`). `Row` inserts the splitters between children by itself.

<Framework name="react">

```tsx title="render-node.tsx"
import { Dockable, type RowNode, type TabsetNode } from "@fragiola/dockable-react";
import type { ReactNode } from "react";
import type { Types } from "./types";

export function renderNode(child: TabsetNode<Types> | RowNode<Types>): ReactNode {
    if (child.type === "tabset") {
        return (
            <Dockable.TabSet node={child} className="tabset">
                <Dockable.TabList<Types> aria-label="Tabs" className="tabs">
                    {(tab) => (
                        <Dockable.Tab node={tab} className="tab">
                            {tab.label}
                        </Dockable.Tab>
                    )}
                </Dockable.TabList>
                <Dockable.TabSetContent />
            </Dockable.TabSet>
        );
    }
    // a nested row: the same function renders its children
    return <Dockable.Row node={child}>{renderNode}</Dockable.Row>;
}
```

</Framework>

<Framework name="vue">

A Vue template owns the recursion with a component that renders itself for a nested row. The
default slot of `Dockable.Row` is called for every child; `typedDockable<Types>()` types the
parts, since a template cannot pass a type argument:

```ts title="dockable.ts"
import { typedDockable } from "@fragiola/dockable-vue";
import type { Types } from "./types";

export const Dockable = typedDockable<Types>();
```

```vue title="LayoutNode.vue"
<script setup lang="ts">
import type { RowNode, TabsetNode } from "@fragiola/dockable-vue";
import { Dockable } from "./dockable";
import type { Types } from "./types";

defineProps<{ node: TabsetNode<Types> | RowNode<Types> }>();
</script>

<template>
    <Dockable.TabSet v-if="node.type === 'tabset'" :node="node" class="tabset">
        <Dockable.TabList v-slot="{ tab }" aria-label="Tabs" class="tabs">
            <Dockable.Tab :node="tab" class="tab">{{ tab.label }}</Dockable.Tab>
        </Dockable.TabList>
        <Dockable.TabSetContent />
    </Dockable.TabSet>
    <!-- a nested row: the same component renders its children -->
    <Dockable.Row v-else :node="node" v-slot="{ node: child }">
        <LayoutNode :node="child" />
    </Dockable.Row>
</template>
```

</Framework>

<Framework name="angular">

An Angular template owns the recursion with template directives. `<ng-template dockableRowChild>`,
placed in `[dockableRow]`, renders every child of the row; a nested row with no template of its
own renders with the same one. Giving a template directive the model types its `let-` variable by
your registry, since a template cannot pass a type argument:

```html title="app.html (the structure)"
<div dockableRow>
    <ng-template [dockableRowChild]="model" let-node>
        @if (node.type === "tabset") {
            <div [dockableTabSet]="node" class="tabset">
                <div dockableTabList aria-label="Tabs" class="tabs">
                    <ng-template [dockableTabListItem]="model" let-tab>
                        <div [dockableTab]="tab" class="tab">{{ tab.label }}</div>
                    </ng-template>
                </div>
                <div dockableTabSetContent></div>
            </div>
        } @else {
            <!-- a nested row: the same template renders its children -->
            <div [dockableRow]="node"></div>
        }
    </ng-template>
</div>
```

</Framework>

</Step>

<Step>

## Render the panels

Tab content does **not** live inside the tabset. `Dockable.Panels` (placed once, directly under
the root) calls its child function for every tab whose content should render, and
`Dockable.Panel` puts the content in an element the engine positions over the tabset's content
area. That is how content survives moves: the element is re-parented, never remounted.

<Framework name="react">

```tsx
<Dockable.Panels<Types>>
    {(tab) => (
        <Dockable.Panel node={tab} className="panel">
            <TabContent tab={tab} />
        </Dockable.Panel>
    )}
</Dockable.Panels>
```

</Framework>

<Framework name="vue">

```vue
<Dockable.Panels v-slot="{ tab }">
    <Dockable.Panel :node="tab" class="panel">
        <TabContent :tab="tab" />
    </Dockable.Panel>
</Dockable.Panels>
```

</Framework>

<Framework name="angular">

```html
<ng-template [dockablePanels]="model" let-tab>
    <div [dockablePanel]="tab" class="panel">
        <tab-content [tab]="tab" />
    </div>
</ng-template>
```

</Framework>

The parts that call a children function (`Row`, `TabList`, `Panels`) take your registry as a type
argument (in Vue, from `typedDockable<Types>()`; in Angular, from the model you give the template
directive): a child cannot infer it from the root. With it, `tab` is a `TabOf<Types>`.

Pick the content from the tab's `component`, as a factory would. The switch narrows `tab.data` to
that component's data, with no cast:

<Framework name="react">

```tsx title="tab-content.tsx"
import type { TabOf } from "@fragiola/dockable-react";
import type { Types } from "./types";

export function TabContent({ tab }: { tab: TabOf<Types> }) {
    switch (tab.component) {
        case "notes":
            // tab.data is { name: string; text: string }
            return <textarea aria-label={tab.label} defaultValue={tab.data.text} />;
        case "welcome":
        case "inspector":
            return <p>{tab.label}</p>;
    }
}
```

</Framework>

<Framework name="vue">

```vue title="TabContent.vue"
<script setup lang="ts">
import type { TabOf } from "@fragiola/dockable-vue";
import type { Types } from "./types";

defineProps<{ tab: TabOf<Types> }>();
</script>

<template>
    <!-- tab.data is { text: string } in this branch -->
    <textarea v-if="tab.component === 'notes'" :aria-label="tab.label" :value="tab.data.text" />
    <p v-else>{{ tab.label }}</p>
</template>
```

</Framework>

<Framework name="angular">

```ts title="tab-content.ts"
import { Component, input } from "@angular/core";
import type { TabOf } from "@fragiola/dockable-angular";
import type { Types } from "./types";

@Component({
    selector: "tab-content",
    template: `
        @let current = tab();
        @if (current.component === "notes") {
            <!-- current.data is { text: string } in this branch -->
            <textarea [attr.aria-label]="current.label" [value]="current.data.text"></textarea>
        } @else {
            <p>{{ current.label }}</p>
        }
    `,
})
export class TabContent {
    readonly tab = input.required<TabOf<Types>>();
}
```

</Framework>

</Step>

<Step>

## Put it together, and give the root a size

<Framework name="react">

```tsx title="app.tsx"
"use client";

import { createModel, Dockable } from "@fragiola/dockable-react";
import { useState } from "react";
import { json } from "./layout";
import { renderNode } from "./render-node";
import { TabContent } from "./tab-content";
import type { Types } from "./types";

export function App() {
    const [model] = useState(() => createModel<Types>(json));
    return (
        <Dockable.Root model={model} style={{ height: "100vh" }}>
            <Dockable.Row<Types>>{renderNode}</Dockable.Row>
            <Dockable.Panels<Types>>
                {(tab) => (
                    <Dockable.Panel node={tab} className="panel">
                        <TabContent tab={tab} />
                    </Dockable.Panel>
                )}
            </Dockable.Panels>
            <Dockable.DropIndicator className="drop-indicator" />
        </Dockable.Root>
    );
}
```

</Framework>

<Framework name="vue">

```vue title="App.vue"
<script setup lang="ts">
import { createModel } from "@fragiola/dockable-vue";
import { Dockable } from "./dockable";
import { json } from "./layout";
import LayoutNode from "./LayoutNode.vue";
import TabContent from "./TabContent.vue";
import type { Types } from "./types";

const model = createModel<Types>(json);
</script>

<template>
    <Dockable.Root :model="model" :style="{ height: '100vh' }">
        <Dockable.Row v-slot="{ node }">
            <LayoutNode :node="node" />
        </Dockable.Row>
        <Dockable.Panels v-slot="{ tab }">
            <Dockable.Panel :node="tab" class="panel">
                <TabContent :tab="tab" />
            </Dockable.Panel>
        </Dockable.Panels>
        <Dockable.DropIndicator class="drop-indicator" />
    </Dockable.Root>
</template>
```

</Framework>

<Framework name="angular">

```ts title="app.ts"
import { Component } from "@angular/core";
import { createModel, DOCKABLE } from "@fragiola/dockable-angular";
import { json } from "./layout";
import { TabContent } from "./tab-content";
import type { Types } from "./types";

@Component({
    selector: "app-root",
    imports: [DOCKABLE, TabContent],
    // the structure and the panels of the steps above, in the root
    templateUrl: "./app.html",
})
export class App {
    readonly model = createModel<Types>(json);
}
```

```html title="app.html"
<div [dockableRoot]="model" style="height: 100vh">
    <div dockableRow>…</div>
    <ng-template [dockablePanels]="model" let-tab>…</ng-template>
    <div dockableDropIndicator class="drop-indicator"></div>
</div>
```

Bootstrap it zoneless, Angular's default: `bootstrapApplication(App)`.

</Framework>

The root **must have a size**: it has no intrinsic size, and an unsized root renders nothing
visible. See [Sizing the root](/docs/getting-started/sizing).

</Step>

## Now style it

At this point the layout works (drag a tab onto the other tabset, drag the splitter, press the
arrow keys on a focused tab) but it is invisible: the package paints nothing. A few rules make
it usable. The selectors use only the `data-*` attributes the primitives expose:

```css title="layout.css"
.tabset { background: Canvas; }
.tabs { display: flex; gap: 2px; min-height: 30px; padding-inline-start: 4px; }
.tab { padding: 4px 12px; cursor: pointer; }
.tab[data-selected] { background: color-mix(in srgb, CanvasText 10%, Canvas); }
.tab[data-dragging] { opacity: 0.4; }
[role="separator"] { background: GrayText; }
[role="separator"][data-orientation="vertical"] { width: 4px; cursor: ew-resize; }
[role="separator"][data-orientation="horizontal"] { height: 4px; cursor: ns-resize; }
.panel { background: Canvas; overflow: auto; }
.drop-indicator { z-index: 10; outline: 2px solid Highlight; }
```

The [plain CSS guide](/docs/guides/styling-css) explains each rule (including why the drop
indicator needs a `z-index`), and the [Tailwind guide](/docs/guides/styling-tailwind) does the
same with utilities.

## What you have

- **Drag and drop**: drag a tab into another tabset, onto a tabset's edge to split it, or to the
  layout's edge. Each drop runs the `tab.move` command, through any middleware you add with
  `model.use`.
- **Splitters**: drag with the pointer, or focus and use the arrow keys (10px per press). They
  have no name yet: [Accessible names](/docs/getting-started/accessible-names) shows how to give
  them one with `renderSplitter` (the `#splitter` slot in Vue, `<ng-template dockableRowSplitter>`
  in Angular).
- **Keyboard**: arrow keys, Home and End move between tabs; Enter or Space selects; `Ctrl+Delete`
  closes a closeable tab.
- **Content that survives**: type in the Notes tab, then drag it to the other tabset. The text is
  still there.

Next, read [the model and commands](/docs/concepts/model-and-commands) to change the layout from
code (`model.run("tab.add", …)`), [typed data](/docs/concepts/typed-data) for everything the
registry types, and [composition](/docs/concepts/composition) for everything you can put in the
recursion.
