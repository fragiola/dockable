<Features columns={4}>
<Feature title="Behaviour">
Resize, drag and drop between tabsets and to the edges, popout windows, maximize, undo/redo.
</Feature>
<Feature title="Accessibility">
The APG tabs pattern, keyboard splitters with ARIA values, focus management, layout paths for
tests.
</Feature>
<Feature title="A JSON model">
The layout is data: load it, save it, intercept every change with onAction.
</Feature>
<Feature title="Primitives">
Root, Row, TabSet, Tab, Panel, Splitter… each renders only what you give it, with render instead
of asChild.
</Feature>
</Features>

<Section title="What it never ships">
<Pills strike items={["CSS", "Icons", "Text", "Rendered menus", "A design system"]} />

The state is exposed as data-\* attributes and ARIA, so any styling solution works: Tailwind,
plain CSS, CSS modules, CSS-in-JS. The examples use Fragiola UI and its palettes.
</Section>
